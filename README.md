# Модуль конфигурирования имитационных моделей виртуального полигона для БАС

Прототип модуля конфигурирования для моделирования сценариев применения беспилотных авиационных систем (БАС) с визуализацией цифровой местности на Unreal Engine 5 и использованием плагина Cesium.

## Описание проекта

Проект представляет собой интерактивный интерфейс, позволяющий пользователю задать координаты (X, Y, Z), после чего камера автоматически перемещается к заданной точке. Используется плоская сцена с цифровой местностью, отображаемой через Cesium. В том числе была решена задача depth from mono.

## Технологический стек

* **Unreal Engine 5**
* **Cesium for Unreal**
* **Blueprints** 
* **UMG** для интерфейса
* **HighResShot** для скриншотов

## Запуск проекта

1. Установите **Unreal Engine 5.3+**
2. Установите плагин [Cesium for Unreal](https://www.cesium.com/unreal/)
3. Откройте проект `.uproject` в UE5
4. Запустите проект
5. В интерфейсе введите координаты и нажмите **Применить**
6. Камера переместится, и начнётся сохранение скриншотов (папка `Unreal Projects\MyProject\Saved\Screenshots\WindowsEditor`)
